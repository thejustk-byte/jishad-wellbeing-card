# Jishad — Wellbeing & Career Guidance Digital Contact Card

A mobile-friendly, single-page digital contact card with a dark forest theme and pastel sage-green accents.

## Sections
- Workplace stress and wellbeing
- Existential reflection and self-awareness
- Early-career mentoring
- Professional background and qualifications
- Email, phone, and WhatsApp contact links

## Publish with GitHub Pages
1. Create a **new** public repository named `jishad-wellbeing-card` in your GitHub account. Do not use either existing repository.
2. Upload `index.html` and `README.md` to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, the site should be available at `https://thejustk-byte.github.io/jishad-wellbeing-card/`.

The website uses only HTML and CSS. It has no build step or external dependencies.
